# Futuretray

Группы приложений на панели задач Windows — быстрая и красивая альтернатива
[taskbar-groups](https://github.com/tjackenpacken/taskbar-groups).

Один значок на панели задач → клик → аккуратное окно с вашими программами, папками и сайтами.

## Что лучше, чем в taskbar-groups

| | taskbar-groups | Futuretray |
|---|---|---|
| Скорость открытия | запуск .NET Framework при каждом клике | ~120 мс: в фоне ждёт процесс, ярлык лишь передаёт ему команду |
| Положение окна | ломается при панели слева/справа/сверху | учитывает любую сторону панели, несколько мониторов, разный масштаб, автоскрытие |
| Внешний вид | WinForms | Windows 11: Acrylic/Mica, скругления, анимации, светлая/тёмная тема |
| Добавление программ | только выбор exe-файла | список всех приложений из «Пуска» (включая Microsoft Store), перетаскивание файлов, папок и ссылок из браузера |
| Значок группы | одна картинка | автоматически собирается из иконок приложений (как папка на iPhone), иконка приложения или своя картинка, любой цвет |
| После изменений | перезакреплять заново | закреплённый значок обновляется сам |
| Ошибки | падает при запуске (`ArgumentOutOfRangeException`) | битые данные чинятся при загрузке, ошибки пишутся в лог, интерфейс не падает |
| Управление | мышь | клавиатура: стрелки, Enter, цифры 1–9, поиск набором текста, Esc |
| Прочее | — | отмена удаления, «Открыть все», запуск от администратора, аргументы, ссылки `steam://`, `discord://`, `tg://`, экспорт/импорт групп, трей, автозапуск |

## Как пользоваться

1. Установите `FuturetraySetup-<версия>.exe` (права администратора не нужны). Дальше программа обновляется сама.
   Можно и без установки — запустить `Futuretray.exe` из постоянной папки, но тогда обновления придут через установщик.
2. **Создать группу** → «Добавить приложение» (или перетащите файлы в окно).
3. **Закрепить на панели задач** → «Показать ярлык» → правой кнопкой по выделенному ярлыку →
   «Закрепить на панели задач» (если пункта нет — «Показать дополнительные параметры»).
   Другой путь: «Добавить в «Пуск»», затем Win → ввести название группы → правой кнопкой →
   «Закрепить на панели задач». Перетаскивание на панель задач Windows 11 для закрепления не поддерживает.
4. Готово: окно само заметит, что значок появился на панели. Клик по значку открывает группу.

Во всплывающем окне:

- клик — запустить; **Ctrl+клик** или средняя кнопка — запустить, не закрывая окно;
- **1–9** — запустить N-е приложение; набор текста — поиск, **Enter** — запустить найденное;
- правая кнопка по значку — «от имени администратора», «открыть расположение»;
- правая кнопка по пустому месту — «Открыть все», «Изменить группу».

## Клавиатура и поиск

- Любой группе можно назначить сочетание клавиш (редактор группы → «Быстрый доступ») — окно группы откроется у курсора.
- **Win+Alt+Space** — поиск по всем группам: набрали пару букв, Enter. Сочетание меняется в настройках.

## Ещё удобства

- Перетащите файл на программу в трее на рабочем столе — файл откроется в ней.
- У ссылок — значки сайтов (Futuretray один раз берёт значок у самого сайта; отключается в настройках).
- **Группа-папка**: меню «…» → «Синхронизировать с папкой» — всё, что появится в папке, появится и в группе.
- **Переезд с Taskbar Groups**: Настройки → «Из Taskbar Groups…» и выберите папку, где лежала та программа.

## Запущенные программы

Как на панели задач: под значком открытой программы — чёрточка (длинная и цветная, если программа активна).
Клик по открытой программе переключает на её окно, повторный — сворачивает, при нескольких окнах — перебирает их.
**Shift+клик** или средняя кнопка — открыть ещё одну копию. Отключается в настройках.

## Трей на рабочем столе

Любую группу можно дополнительно вывести отдельной панелью прямо на рабочий стол:
редактор группы → «Трей на рабочем столе».

- **Положение**: слева, сверху, справа, снизу (с выравниванием в начале/по центру/в конце и выбором монитора)
  или «Свободно» — трей перетаскивается за ручку, а у края экрана сам прилипает к нему.
- **Поверх всех окон** — или жить на рабочем столе под окнами (по Win+D не пропадает).
- **Прятать за край экрана** — трей уезжает и выезжает при наведении мыши.
- **Резервировать место** — как панель задач: развёрнутые окна не заходят под трей.
- Трей не забирает фокус и уходит назад в полноэкранных играх и видео.
- Правой кнопкой по трею — быстрые настройки без открытия редактора.

## Где лежат данные

- Настройки и группы: `%APPDATA%\Futuretray\config.json` (+ `.bak`)
- Ярлыки и иконки групп: `%APPDATA%\Futuretray\Shortcuts`, `...\Icons`
- Лог ошибок: `%LOCALAPPDATA%\Futuretray\logs\futuretray.log`

Если перенести `Futuretray.exe` в другую папку, ярлыки починятся сами при следующем запуске.

## Сборка

Нужен .NET 9 SDK.

```bash
dotnet build src/Futuretray
```

```bash
pwsh tools/release.ps1
```

Скрипт собирает `dist/Futuretray.exe` (один файл, .NET ставить не нужно), `dist/Futuretray.zip`
и установщик `dist/FuturetraySetup-<версия>.exe` (нужен Inno Setup 6).

## Выпуск новой версии и автообновление

Программа раз в 12 часов (и через 20 секунд после запуска) смотрит последний релиз в
GitHub Releases репозитория `Nyan4eg/Futuretray`. Если там версия новее, она предлагает обновиться:
скачивает `FuturetraySetup-*.exe`, сверяет контрольную сумму и ставит его тихо — установщик сам
закрывает программу и запускает новую версию.

Как выпустить версию:

1. Опишите изменения в `CHANGELOG.md` в разделе `## X.Y.Z`.
2. Поднимите `<Version>` в `src/Futuretray/Futuretray.csproj`, закоммитьте и запушьте тег:

```bash
git tag v1.2.0
```

```bash
git push origin main --tags
```

GitHub Actions (`.github/workflows/release.yml`) соберёт установщик и опубликует релиз.
Без CI то же самое делает `pwsh tools/release.ps1 -Publish`.

Отладка: `Futuretray.exe --snapshot <папка>` (только в Debug) рисует окна в PNG; переменная
окружения `FUTURETRAY_DATA` подменяет папку данных.

## Как устроено

- `Program.cs` — точка входа. Если фоновый хост уже работает, команда уходит ему по именованному
  каналу, и процесс сразу завершается (WPF при этом даже не загружается).
- Ярлык группы: `Futuretray.exe --group <id>` с уникальным AppUserModelID, поэтому Windows
  не склеивает разные группы в один значок.
- `Core/TaskbarInfo.cs` — определение стороны панели задач и расчёт положения окна.
- `Core/ShortcutManager.cs` — ярлыки, `.ico` групп, обновление уже закреплённых копий.
- `UI/PopupWindow` — всплывающее окно группы, `UI/MainWindow` — редактор.
